# FACE_RECOGNITION

This project is a face recognition-based attendance system built with Python, OpenCV, and SQLite.

## Features
- Detects faces using the `face_recognition` library
- Marks attendance in a database (`attendance.db`)
- Stores known faces for recognition

## How to Run
1. Install requirements: `pip install opencv-python face_recognition`
2. Run the script: `python main.py`
